# Ziron

Minimal AI assistant - Telegram Bot + OpenRouter integration.

A clean, lightweight implementation that connects Telegram bots to AI models via OpenRouter.

## Features

- ✅ **Telegram Bot API** (via Grammy)
- ✅ **OpenRouter** integration (Claude, GPT-4, 200+ models)
- ✅ **OpenAI** integration (API key or OAuth)
- ✅ **OAuth support** (ChatGPT Plus / OpenAI Codex)
- ✅ **JSON config** (auto-generated)
- ✅ **Config management** CLI commands
- ✅ Clean JavaScript codebase (~1,300 LOC)

## Quick Start

### 1. Install

```bash
npm install
```

### 2. Get Credentials

**OpenRouter API Key:**
- Sign up at [OpenRouter](https://openrouter.ai)
- Get your API key from [Settings → Keys](https://openrouter.ai/settings/keys)

**Telegram Bot Token:**
- Open Telegram and message [@BotFather](https://t.me/botfather)
- Send `/newbot` and follow the prompts
- Copy the bot token you receive

### 3. Configure

```bash
# Copy example env file
cp .env.example .env

# Edit .env and add:
OPENROUTER_API_KEY=your_openrouter_key
TELEGRAM_BOT_TOKEN=your_telegram_bot_token
```

### 4. Verify Setup

```bash
node ziron.mjs onboarding
```

This will validate both credentials and test connections.

### 5. Start the Bot

```bash
node ziron.mjs telegram connect
```

Now message your bot on Telegram - it will respond using AI! 🤖

## Commands

### Setup & Testing
```bash
ziron onboarding         # Validate configuration & generate config.json
ziron test-openrouter    # Test OpenRouter connection only
```

### Configuration
```bash
ziron config show        # Show current configuration
ziron config get <key>   # Get a config value
ziron config set <key> <value>  # Set a config value
```

### Authentication
```bash
ziron auth openai-oauth  # Login to OpenAI via OAuth (ChatGPT Plus)
```

**OAuth Flow:**
- Opens browser for OpenAI login
- No API key needed
- Access ChatGPT Plus models (GPT-5.4, GPT-5.4-mini)
- Credentials saved to config.json

### Telegram Bot
```bash
ziron telegram connect   # Start the bot (keeps running)
ziron telegram status    # Check bot token validity
ziron telegram test      # Test full integration
```

## Bot Commands

Once running, your bot responds to:
- `/start` - Welcome message
- `/help` - Show available commands
- `/ping` - Test if bot is alive
- Any text message - Get an AI response

## Configuration

Configuration is loaded in this order (later sources override earlier):
1. `config.json` (generated by onboarding)
2. `.env` file
3. Environment variables

### Environment Variables (.env)

```env
# AI Providers (choose one or both)
OPENROUTER_API_KEY=sk-or-...    # From https://openrouter.ai/settings/keys
OPENAI_API_KEY=sk-...           # From https://platform.openai.com/api-keys

# Telegram
TELEGRAM_BOT_TOKEN=123456:ABC...  # From @BotFather
```

### Config File (config.json)

Generated automatically by `ziron onboarding`:

```json
{
  "version": "0.1.0",
  "providers": {
    "openrouter": {
      "apiKey": "sk-or-...",
      "model": "anthropic/claude-3.5-sonnet",
      "maxTokens": 500
    },
    "openai": {
      "apiKey": "sk-...",
      "model": "gpt-4",
      "maxTokens": 500
    }
  },
  "telegram": {
    "botToken": "123456:ABC..."
  }
}
```

Modify with:
```bash
ziron config set providers.openrouter.model "gpt-4"
ziron config show
```

## Architecture

```
ziron/
├── src/
│   ├── cli/              # CLI commands
│   ├── channels/telegram/ # Telegram bot client (Grammy)
│   ├── providers/        # OpenRouter API client
│   ├── config/           # Configuration loader
│   └── utils/            # Logger
└── ziron.mjs            # CLI entrypoint
```

## Tech Stack

- **Runtime**: Node.js 20+
- **Telegram**: [Grammy](https://grammy.dev) (Telegram Bot API)
- **AI**: [OpenRouter](https://openrouter.ai) (OpenAI-compatible API)
- **CLI**: [Commander.js](https://github.com/tj/commander.js)
- **Config**: dotenv + YAML

## Troubleshooting

**Bot not responding:**
- Check `TELEGRAM_BOT_TOKEN` is correct
- Check `OPENROUTER_API_KEY` is valid
- Run `ziron telegram test` to diagnose

**"Invalid bot token":**
- Get a new token from @BotFather
- Make sure you copied the complete token

**OpenRouter errors:**
- Verify your API key at https://openrouter.ai/settings/keys
- Check you have credits/billing set up
